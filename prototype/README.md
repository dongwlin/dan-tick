# dan-tick UI 原型

独立于 Wails/Vue 正式前端的 **Vanilla Web** 界面探索版本。

```sh
cd prototype
pnpm install
pnpm dev
```

打开终端提供的本地地址（默认 `http://localhost:5173`）。

可预览仪表盘、弹幕任务、直播间、执行记录、设置和任务编辑；左上角切换展开/收起导航，左下角是唯一的 B 站账号头像占位。顶部是自绘窗口标题栏，右侧有最小化、最大化、关闭按钮。独立浏览器预览无法控制原生窗口，点击会给出说明；待集成到 Wails 后才会接入真实窗口操作。所有内容均为**演示数据**，本地操作只影响当前浏览器会话，刷新后恢复初始状态；不会真的发送弹幕、读取 B 站账号或更改系统设置。

直播间页默认显示卡片，右上角可以切换为紧凑列表。视图选择在页面导航时保留，刷新后恢复为卡片视图。

执行 `pnpm build` 会先检查 TypeScript 类型再构建静态资源。

## 源码结构

- `src/main.ts`：启动入口；`src/app.ts`：路由、渲染与统一事件处理。
- `src/state.ts`、`src/data.ts`：当前会话的模拟状态、类型、示例数据和时间计算。
- `src/shell.ts`、`src/ui.ts`：侧边栏 / 标题栏和跨页面共用的 HTML 片段。
- `src/pages/`：总览、任务、任务编辑、直播间、执行记录、设置的页面渲染。
- `src/style.css`、`src/styles/`：样式入口与按职责拆分的 CSS，响应式规则集中在 `responsive.css`。

页面渲染只读取演示状态；操作由 `app.ts` 的事件委托处理，避免页面文件间互相调用。
