# dan-tick UI 原型

独立于 Wails/Vue 正式前端的 **Vanilla Web** 界面探索版本。

```sh
cd prototype
pnpm install
pnpm dev
```

打开终端提供的本地地址（默认 `http://localhost:5173`）。

可预览仪表盘、弹幕任务、直播间、执行记录、设置和任务编辑；左侧是固定的图标导航，左下角是唯一的 B 站账号头像占位。顶部是包含 `dantick` 品牌文字的自绘窗口标题栏，右侧有最小化、最大化、关闭按钮。独立浏览器预览无法控制原生窗口，点击会给出说明；待集成到 Wails 后才会接入真实窗口操作。所有内容均为**演示数据**，本地操作只影响当前浏览器会话，刷新后恢复初始状态；不会真的发送弹幕、读取 B 站账号或更改系统设置。

桌面设计基准：**最小窗口 1080 × 680，默认窗口 1280 × 760**（逻辑像素）。各页面在桌面设计尺寸内使用固定的主页面框架，不产生整体横向或纵向滚动；任务、记录、直播间、设置和任务编辑在各自内容区域内按需滚动。总览页根据视口高度展示 2～5 条最近执行记录，其他记录可从「全部记录」进入。低于最小宽度的浏览器预览允许退化为页面滚动，以保留全部操作。

直播间页默认显示卡片，右上角可以切换为紧凑列表。视图选择在页面导航时保留，刷新后恢复为卡片视图。

列表交互约定：**执行记录采用页码分页**，根据可用高度确定每页条数，演示数据包含多页，上一页／页码／下一页均可操作；筛选后重置到第一页，筛选结果一页内可完整显示时隐藏分页控件。最后一页未铺满时也显示列表结束分割线（和「已到最后一页」提示），其他未分页的小列表沿用「已全部显示」提示。**弹幕任务和直播间采用游标增量加载**作为正式版规划（滚动加载下一批、保留加载更多入口，无页码）；当前原型任务与直播间仍是完整的会话内演示数据，尚未连接真实游标接口。总览只显示少量摘要，「最近执行」表头固定在数据滚动容器外侧，滚动条从记录行开始。

设置页「数据与日志」包含「打开日志目录」按钮。浏览器原型点击后只显示说明，不会尝试访问本机文件系统；正式桌面版将通过系统文件管理器打开诊断日志目录。

执行 `pnpm build` 会先检查 TypeScript 类型再构建静态资源。

## 源码结构

- `src/main.ts`：启动入口；`src/app.ts`：路由、渲染与统一事件处理。
- `src/state.ts`、`src/data.ts`：当前会话的模拟状态、类型、示例数据和时间计算。
- `src/shell.ts`、`src/ui.ts`：侧边栏 / 标题栏和跨页面共用的 HTML 片段。
- `src/pages/`：总览、任务、任务编辑、直播间、执行记录、设置的页面渲染。
- `src/style.css`、`src/styles/`：样式入口与按职责拆分的 CSS，响应式规则集中在 `responsive.css`。

页面渲染只读取演示状态；操作由 `app.ts` 的事件委托处理，避免页面文件间互相调用。
