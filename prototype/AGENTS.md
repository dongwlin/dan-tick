# dan-tick 前端原型工作约定

本目录是用于讨论 UI、页面结构和交互的 **独立演示原型**，不是正式 Wails 前端。正式产品需求见 `../docs/PRD.md`，技术决策见 `../docs/技术栈选型.md`，视觉与无障碍原则见 `../docs/specs/`。本原型的 Vanilla TypeScript 是有意选择，不代表修改正式应用的 Vue 技术选型。

## 技术与边界

- 使用 Vite、原生 TypeScript、原生 CSS 和 pnpm；不用前端框架、组件框架或额外的状态管理层。
- `src/main.ts` 只负责启动；`src/app.ts` 集中处理路由、重绘和事件；`src/state.ts` 保存当前会话的演示状态，`src/data.ts` 放类型、示例数据及时间计算。
- 各页面的 HTML 由 `src/pages/` 下对应文件负责；`src/shell.ts` 维护侧边栏和标题栏，`src/ui.ts` 只放确实被多个页面复用的渲染片段、文本转义和图标。新需求优先修改对应页面，不另建状态层或通用组件体系。
- `src/style.css` 是样式导入入口；`src/styles/` 按基础与窗口布局、仪表盘、通用组件、其他页面和响应式规则划分。遵循现有语义类名，不为原型引入 CSS-in-JS 或构建插件。
- 所有任务、直播间、执行记录、账号状态均是**演示数据**；允许在当前页面会话中操作，刷新后恢复默认数据。绝不调用真实 B 站接口，不录入或存储真实 Cookie，不伪装为完成业务执行。
- 与项目规范保持一致：Go 未来是业务状态来源；账号凭证属于系统安全存储职责，不进入 Web Storage。原型中可使用 `localStorage` **仅保存 UI 主题偏好**。
- 界面采用固定图标式左侧导航，底部预留 B 站用户头像；以可见状态、原生语义、键盘可操作性为先。
- 顶部是自绘 Wails 风格的**窗口标题栏**，不是页面导航；右侧只展示最小化、最大化、关闭，账号头像只出现于侧栏左下角。独立浏览器原型不能控制原生窗口，点击时应明确提示，不要模拟已完成窗口操作。标题栏预留 Wails 拖动区域。
- CSS 遵循亚克力设计系统：不使用渐变，强调色冷蓝青，深浅主题共用布局，实心表单控件，高密度信息可读。
- 页面按轻量桌面工具设计：优先让调度状态、下次执行、异常、任务操作可见。保留适度空间和冷蓝青强调，不使用没有业务内容的欢迎横幅、伪直播封面、圆形图标占位或泛化宣传副标题；功能性文字至少 11px。
- 目标桌面窗口最小尺寸为 1080 × 680，默认尺寸为 1280 × 760。所有页面在最小尺寸及以上保持主页面横纵方向不滚动；需要浏览较多内容时为页面内列表、表单等区域设置独立滚动，并确保主要操作始终可用。浏览器视口低于桌面最小尺寸时可以退化为页面滚动以保证可访问。
- 直播间提供卡片和列表两种可切换视图，默认卡片。卡片保留适度的色块视觉作为分组背景，但显示真实房间 ID，不要使用无意义的序号。切换只保留在当前会话状态，不存储额外的业务偏好。

## 开发和验证

```sh
cd prototype
pnpm install
pnpm dev
pnpm build
```

不修改 `../frontend/`、Go 或 Wails 构建流程。对 UI 的迭代先改这个原型，后续再讨论如何迁移到正式 Vue 前端。不要提交 `node_modules/`、`dist/`。
