# 开机自启动验收

功能对应 [FR-029](PRD.md#fr-029开机自启动设置)，入口位于设置页「窗口与后台运行」之后。使用说明及系统限制见 [README](../README.md#开机自启动)。本次实现开启、关闭和状态反馈；启动后隐藏窗口仍是独立待办。

## 2026-10-14 验证记录

Go 测试覆盖默认关闭、开启 / 关闭、外部修改、旧路径修复与清理、路径引用、取消、并发和安全错误；Linux 使用临时文件，Windows 注册表边界使用替身，不操作真实用户启动项。前端行为测试覆盖加载、读取失败与重试、进行中禁用、成功反馈、保存失败后的事实状态重读、不支持与旧启动项清理。

全仓 Go 测试、`go vet` 与 Race Detector 通过；前端 154 项测试、lint、格式检查和构建通过。Linux 生产桌面构建与 Windows 生产桌面交叉编译通过，Windows 平台单元测试也已交叉编译。

在 Fedora 44、GTK 4.22.5、WebKitGTK 2.54.1 上，通过 `WAILS_MCP=1 wails3 dev` 的真实 WebView 验证：

- 初始关闭，开启后 Binding 返回已启用，生成的用户启动项通过 `desktop-file-validate`。
- 关闭后启动项被删除；外部替换为旧路径后，刷新显示修复提示，清理按钮删除旧项。
- Tab 能聚焦开关，Enter 能触发开关操作；1280 × 760 与 1080 × 680 窗口中的控件可见。

桌面检查使用隔离数据 / 配置目录与不提供凭证服务的私有 D-Bus 会话。窗口结构由 Wails MCP 的 DOM 快照检查；未以该快照代替像素外观或屏幕阅读器验收。检查结束后删除临时启动项并停止开发版。

## 待实机验收

| 平台 | 操作 | 预期 |
| --- | --- | --- |
| Windows 10 / 11 | 开启后注销并重新登录桌面 | 应用显示主窗口；重复手动启动只恢复已有窗口 |
| Windows 10 / 11 | 在系统「启动应用」禁用后重新登录 | 应用不启动；在系统重新启用后能启动，设置页显示的是本应用注册项状态 |
| Windows 10 / 11 | 移动应用后在新位置开启，再关闭 | 更新为新路径，关闭清理本应用注册项 |
| Linux | 开启后注销并重新登录桌面 | 桌面会话读取用户启动项并显示应用主窗口 |
| Linux AppImage | 在无 FUSE 的环境开启后重新登录 | 原始 AppImage 通过提取运行模式启动；含空格路径可用 |
| Windows / Linux | 关闭后重新登录 | 应用不再自动启动 |

Windows 运行行为、完整注销 / 登录、实际 AppImage 自动启动和其他 Linux 桌面环境仍待上述实机验收；交叉编译、单元测试及开发 WebView 检查不能替代这些结果。
