# Vue SPA Pack

## 1. 用途

本 Pack 是 Vue SPA 项目的规范加载入口，只组合已有 Standard 与 Profile，不定义新规则。

## 2. 基线文档

项目采用本 Pack 时加载：

- [[前端应用架构规范]]
- [[前端测试规范]]
- [[前端交互与可访问性规范]]
- [[HTTP API 设计规范]]
- [[前端 SPA 基础技术栈]]
- [[Vue SPA 技术栈]]
- [[Vue SPA 架构约定]]
- [[Vue SPA 测试约定]]

HTTP 边界的响应契约以《[[HTTP API 设计规范]]》为准，前端测试与 Mock 依赖该契约。

## 3. 可组合 Profile

项目按实际选择叠加：
